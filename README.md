## Descripción

Dashboard multi-página en Power BI para el restaurante Juaco, analizando 12 meses de datos de ventas (Feb 2014 – Ene 2015). El análisis identificó la caída en ventas de vinos como driver principal del declive de ingresos del restaurante.

---

## Páginas del dashboard

| Página | Contenido |
|--------|-----------|
| 1 | Análisis general de ventas por mes, categoría y tipo de cliente |
| 2 | Análisis de vinos y rendimiento por mesero |
| 3 | Ticket promedio y distribución de ventas por horario |

---

## Hallazgos principales

- 📌 La caída de ventas se explica directamente por el colapso de ventas de vino desde septiembre — categoría que representa el tercer mayor ingreso del restaurante.
- 📌 Los clientes frecuentes, que solían consumir vino regularmente, dejaron de hacerlo en septiembre sin ser reemplazados por otra categoría.
- 📌 El ticket promedio cayó paulatinamente desde el pico de abril — menos visitas y menor gasto por visita.
- 📌 Alta proporción de clientes nuevos vs. clientes repetitivos — oportunidad de mejora en fidelización.
- 📌 El mesero Mauricio no registra ventas de vino — oportunidad de capacitación para incrementar ingresos.
- 📌 La mayor concentración de ventas ocurre después de las 9pm, confirmando perfil de restaurante nocturno.
